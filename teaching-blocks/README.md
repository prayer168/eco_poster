# 新增 10 組教學海報與六區塊版

本資料夾包含 N01–N10 的獨立 A2 SVG 後製版。每張 SVG 有六個固定留白區，先放入版面，再由教師或學生在 Canva、PowerPoint、Affinity Publisher 或 SVG 編輯器中填入文字。

固定六區塊：

1. 我看見什麼？（物種與環境辨識）
2. 牠如何生活？（形態、行為與生活史）
3. 牠與誰有關？（食物網、授粉、棲地關係）
4. 它面臨什麼問題？（威脅與環境變化）
5. 我如何知道？（觀察證據、資料或紀錄）
6. 我可以採取什麼行動？（個人、校園與社區行動）

SVG 使用英文短標題是為了避免 AI 或編碼造成中文字形錯誤；正式繁體中文請在排版階段加入。
